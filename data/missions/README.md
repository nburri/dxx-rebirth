# Bundled missions

Two levels made for this fork's group, generated by our own level generator
(see the level design notes kept with the generator; no geometry from other
levels was copied). They reference the original Descent 2 textures by index
only, so they need the Descent 2 game data like any custom mission.

| File | Mission | Mode |
|---|---|---|
| GGCKEEP3.HOG / .MN2 | GGC Crucible Keep v3 | anarchy, 8 players |
| GGCFORG3.HOG / .MN2 | GGC Twin Forges v3 | CTF Classic (also CTF/anarchy) |

Licence: CC0 1.0 (public domain dedication).

The host also sends missions automatically to players who lack them
(Options → Gameplay → "Accept missions from the host").
